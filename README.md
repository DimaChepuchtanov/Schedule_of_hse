# Schedule_of_hse

## Инициализация схемы базы данных

При запуске через Docker Compose сервис `db-init` создаёт схему `identity` в
PostgreSQL до запуска миграций Django. SQL-команда идемпотентна: существующая
схема не удаляется и не пересоздаётся.

## Frontend

Страницы находятся в `frontend/src/pages/` и подключаются автоматически по имени файла.
Порядок добавления страницы, структура модулей и команды запуска описаны в
[frontend/README.md](frontend/README.md).

## Проверка исходных данных

Страница `/data-import/` проверяет выбранный Excel-файл или ручной ввод.
Файл содержит один лист выбранного типа: `Группы`, `Преподаватели` или
`Доступность`. После проверки данные отображаются в предпросмотре.
