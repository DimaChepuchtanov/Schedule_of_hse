# Разработка интеллектуальной системы автоматического составления и корректировки расписания учебных занятий для образовательных организаций

Система предназначена для автоматизации процесса формирования непротиворечивого расписания с учётом правил и регламентов образовательной организации, а также для оперативной корректировки расписания при изменении условий (болезнь преподавателя, недоступность аудитории и т.п.). В рамках проекта рассматривается составление расписания для бакалавриата очной формы обучения.

## Цель проекта

К 15 декабря 2026 года обеспечить администратора образовательной организации инструментом автоматического составления расписания для бакалавриата очной формы обучения, который сократит время на формирование расписания на 40% и снизит количество конфликтов в расписании на 50%.

## Задачи проекта

- загружать учебные планы и настраивать правила (доступность преподавателей, вместимость аудиторий, количество занятий);
- автоматически формировать расписание без пересечений преподавателей, групп и аудиторий;
- формировать расписание с минимальным количеством «окон» и равномерной нагрузкой;
- оперативно корректировать расписание при изменениях и вручную редактировать его;
- просматривать полное расписание;
- выгружать готовое расписание в Excel;
- обеспечить просмотр расписания через UI неавторизованному пользователю.

## Ключевой результат MVP

В рамках MVP предполагается система, способная генерировать расписание с учётом входных данных и возможным изменением впоследствии. Администратор загружает учебные планы, списки преподавателей, групп, дисциплин и аудиторий, а также задаёт правила (доступность преподавателей, вместимость аудиторий, количество занятий). Система автоматически формирует расписание без пересечений, с минимальным количеством «окон» и равномерной нагрузкой, после чего готовое расписание отображается в интерфейсе и доступно для просмотра неавторизованному пользователю через UI. После автоматической генерации администратор может вручную отредактировать расписание, а при изменении условий — ввести новые параметры, и система пересчитает расписание с их учётом. Готовое расписание можно выгрузить в Excel. MVP охватывает составление расписания только для бакалавриата очной формы обучения.
