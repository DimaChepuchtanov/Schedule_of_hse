# Schedule_of_hse

## Инициализация схемы базы данных

При запуске через Docker Compose сервис `db-init` создаёт схему `identity` в
PostgreSQL до запуска миграций Django. SQL-команда идемпотентна: существующая
схема не удаляется и не пересоздаётся.

## Frontend

Страницы находятся в `frontend/src/pages/` и подключаются автоматически по имени файла.
Порядок добавления страницы, структура модулей и команды запуска описаны в
[frontend/README.md](frontend/README.md).

## Проверка исходных данных

Страница `/data-import/` проверяет Excel-файл без записи в базу данных. Файл
должен содержать один выбранный лист (`Группы`, `Преподаватели` или
`Доступность`) и точные заголовки для этого типа:

- `Группы`: `Группа`;
- `Преподаватели`: `Фамилия`, `Имя`, `Отчество`, `Должность`;
- `Доступность`: `Фамилия`, `Имя`, `Отчество`, `Дни недели`.

В поле `Дни недели` несколько дней указываются через запятую.

После успешной проверки данные показываются в предпросмотре как записи
системы.
